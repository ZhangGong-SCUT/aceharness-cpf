## 报告生成规则

1. **完整性**：所有章节必须填写，无内容的标注"不适用"
2. **准确性**：根因结论必须基于证据链
3. **可读性**：使用 Markdown 格式，表格和代码块清晰
4. **可执行性**：修复建议必须具体可操作
5. **可追溯性**：所有结论附证据来源
